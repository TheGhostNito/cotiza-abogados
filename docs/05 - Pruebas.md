# Pruebas realizadas

← [Volver al inicio](00%20-%20Inicio.md)

Las comprobaciones fueron manuales sobre el prototipo. No existe una suite de pruebas automatizadas en el repositorio.

## Resultados comprobados

| Recorrido | Resultado |
|---|---|
| Registro y fotografía | El formulario validó los datos de demostración y mostró la vista previa de la imagen seleccionada. |
| Inicio de sesión | Se completó el flujo simulado y se mostró su confirmación sin crear una sesión real. |
| Buscador y filtros | Se comprobaron búsquedas por contenido y el filtro de modalidad. |
| Búsquedas con resultados | Se mostraron las coincidencias y su resumen. |
| Búsquedas sin resultados | Se mostró ayuda para editar, restablecer o quitar el filtro de modalidad según el caso. |
| Perfiles de abogados | Se abrieron las fichas con sus datos ficticios y modalidades. |
| Cotizaciones | Se completó el formulario y se mostró la confirmación correspondiente. |
| Regreso al perfil | Después de una cotización iniciada desde una ficha, fue posible volver al mismo perfil. |
| Contacto | Se completó el formulario de demostración y se mostró la confirmación sin envío real. |

## Revisión móvil

Durante el desarrollo se reportaron pruebas móviles y la Fase 3 incorporó mejoras específicas para esa experiencia. La implementación incluye menú adaptable, controles con áreas táctiles, formularios en una columna y ajustes para diálogos y tarjetas en anchos pequeños.

No quedó registrado un listado de dispositivos, navegadores ni resoluciones concretas. Por esa razón, esta nota no atribuye la prueba a equipos específicos ni presenta una matriz de compatibilidad.
