# Vía Legal — Documentación del proyecto

> [!info] Estado documentado
> Cierre de las tres fases del prototipo, realizado el **19 de noviembre de 2026**.

Vía Legal es un prototipo web para explorar áreas de práctica legal, revisar perfiles ficticios de abogados y ensayar una solicitud de cotización. Esta bóveda resume qué se construyó, cómo evolucionó y qué se comprobó durante el desarrollo.

## Resumen rápido

- **Producto:** prototipo público y local, sin servicios externos.
- **Tecnología:** HTML, CSS y JavaScript sin dependencias.
- **Evolución:** tres fases integradas desde `dev` hacia `main` mediante los PR #1, #2 y #3.
- **Estado final:** buscador y filtros, perfiles ficticios, cotizaciones y formularios de demostración, con mejoras de navegación y adaptación móvil.

## Fuentes utilizadas

La documentación se preparó a partir del código actual, `README.md` y el historial local de Git del repositorio `cotiza-abogados`. Las pruebas manuales corresponden a las comprobaciones realizadas durante el trabajo; no se añadieron resultados que no estuvieran registrados o confirmados.
