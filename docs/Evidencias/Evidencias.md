## Cómo incorporarlas

Guarda las imágenes en `Evidencias/Capturas` y enlázalas desde esta nota. Un formato sencillo es:

```md
![Descripción de la captura](Capturas/nombre-de-la-captura.png)
```

Conviene acompañar cada imagen con una frase breve que indique el recorrido mostrado y, para las capturas móviles, el dispositivo o ancho de pantalla si ese dato está disponible.
